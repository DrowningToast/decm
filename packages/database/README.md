# DECM Database Package

This package contains SQL migrations and generated Go queries for the DECM platform using sqlc.

## Features

- SQL migrations for database schema management
- Automatic Go query generation using sqlc
- PostgreSQL with UUID and timestamp support
- Type-safe database operations

## Structure

```
packages/database/
├── migrations/          # SQL migration files
├── queries/            # SQL query definitions
├── go/                 # Generated Go code
│   └── generated/      # Generated by sqlc
├── sqlc.yaml          # sqlc configuration
└── package.json       # Package configuration
```

## Usage

### Prerequisites

Install required tools:
```bash
# Install sqlc
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest

# Install migrate tool
go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest
```

### Running Migrations

```bash
# Set database URL
export DATABASE_URL="postgres://user:password@localhost:5432/decm?sslmode=disable"

# Run migrations up
bun migrate:up

# Run migrations down
bun migrate:down

# Create new migration
bun migrate:create migration_name
```

### Generating Queries

```bash
# Generate Go code from SQL queries
bun generate
```

## Integration

This package is designed to be imported by the backend service:

```go
import "decm-backend/packages/database/go/generated"
```

## Database Schema

The database uses PostgreSQL with required extensions that are automatically installed via migrations:
- **uuid-ossp** - UUID generation for primary keys and unique identifiers
- **pg_trgm** - Trigram matching for full-text search on users and events  
- **citext** - Case-insensitive text data type for emails and usernames
- **pgcrypto** - Cryptographic functions for blockchain integration and security

### Migration Structure
1. **000001_enable_extensions** - Installs required PostgreSQL extensions
2. **000002_create_core_tables** - Creates all core DECM platform tables

## Query Development

1. Write SQL queries in `queries/` directory
2. Run `bun generate` to generate Go code
3. Import generated code in your Go application
4. Use type-safe database operations
